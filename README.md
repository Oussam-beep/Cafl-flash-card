

#Project Name: Flashcard Quiz App
Description
The Flashcard Quiz App is a Flutter-based mobile application designed to help users learn and test their knowledge using flashcards. Users can register, create decks, take quizzes, view scores, and manage their profiles and settings. The app provides a user-friendly interface for interactive learning.

Features
Login & Registration

Secure authentication for users to create accounts or log in.
Home Screen

Displays a list of available decks and quizzes.
Decks Screen

Allows users to view, add, and manage flashcard decks.
Quiz Screen

Users can attempt quizzes based on their selected deck.
Score Screen

Displays users' quiz results and performance stats.
Profile Screen

Users can update their personal information.
Settings Screen

Customize app preferences like themes or notifications.
Technology Stack
Framework: Flutter
Language: Dart
Tools: Android Studio / VS Code, GitHub
Screens Overview
Login/Registration: User authentication.
Home: Dashboard for accessing decks and quizzes.
Decks: View, add, and edit flashcards.
Quiz: Interactive quiz-taking functionality.
Score: Displays quiz performance.
Profile: Update user information.
Settings: Configure app preferences.
